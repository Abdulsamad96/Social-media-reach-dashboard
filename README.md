
# 📊 Social Media Engagement Analysis – Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing social media engagement data using Microsoft Power BI. The dashboard provides an interactive and visual representation of social media performance across different platforms, post types, posting times, and sentiment categories.

The goal is to identify engagement patterns and provide data-driven insights into social media content performance.

## 🎯 Objectives

- Analyze social media engagement across different platforms.
- Compare likes, comments, and shares.
- Identify engagement patterns based on post types.
- Analyze posting days and times.
- Understand sentiment distribution.
- Build an interactive Power BI dashboard for data visualization.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Data analysis and calculated measures
- **CSV Dataset**
- **Data Visualization**

## 📂 Dataset Description

The dataset contains social media post engagement information.

### Dataset Features

| Column | Description |
|---|---|
| post_id | Unique identifier for each post |
| platform | Social media platform |
| post_type | Type of content posted |
| post_time | Date and time of the post |
| likes | Number of likes |
| comments | Number of comments |
| shares | Number of shares |
| post_day | Day of the week |
| sentiment_score | Sentiment category of the post |

## 📊 Dashboard Features

- **Platform Analysis:** Compare engagement across social media platforms.
- **Engagement Metrics:** Analyze likes, comments, and shares.
- **Content Analysis:** Explore performance by post type.
- **Time Analysis:** Examine posting days and times.
- **Sentiment Analysis:** Visualize positive, neutral, and negative sentiment categories.
- **Interactive Filters:** Filter the dashboard based on relevant categories.

## 🔄 Project Workflow

1. Import the CSV dataset into Power BI.
2. Clean and transform the data using Power Query.
3. Format date and time fields.
4. Create calculated columns and measures using DAX.
5. Design interactive dashboard visualizations.
6. Analyze social media engagement patterns.
